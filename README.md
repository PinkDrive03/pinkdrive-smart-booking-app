# PinkDrive - Ứng dụng mô phỏng đặt xe và giao đồ ăn

PinkDrive là ứng dụng web mô phỏng nền tảng đặt xe và giao đồ ăn. Ứng dụng hỗ trợ chọn điểm đi/điểm đến trên bản đồ, tìm tài xế phù hợp, tính giá động, theo dõi hành trình, xuất hóa đơn chi tiết, đánh giá tài xế, tip tài xế và xem lịch sử chuyến đi.

## Chức năng chính

- Chọn dịch vụ: đặt xe hoặc giao đồ ăn
- Chọn điểm đón, điểm đến hoặc quán ăn trên bản đồ
- Gợi ý địa điểm và lấy địa chỉ từ bản đồ
- Vẽ tuyến đường và tính khoảng cách di chuyển
- Tự động dự đoán điều kiện chuyến đi: thời tiết, giao thông, nhu cầu và thời gian
- Tính giá động dựa trên quãng đường, loại dịch vụ, thời tiết, giao thông, nhu cầu và thời gian
- Hiệu ứng radar tìm tài xế/shipper gần nhất
- Chọn tài xế tối ưu dựa trên thời gian đến đón
- Theo dõi xe di chuyển trên bản đồ
- Cho phép hủy chuyến nếu thời gian chờ tài xế quá lâu
- Hiển thị hóa đơn chi tiết sau khi hoàn thành chuyến đi
- Đánh giá và tip tài xế
- Lưu lịch sử chuyến đi

## Công nghệ sử dụng

- Node.js
- Express.js
- JavaScript
- HTML/CSS
- Leaflet Map
- OpenStreetMap
- OSRM Routing API
- Open-Meteo Weather API
- LocalStorage
- Prisma
